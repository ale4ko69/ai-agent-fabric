# Evidence

Store command output, source excerpts, validation reports, and review evidence here.
Do not store credentials, tokens, passwords, or other secrets.

`cli-skills-disposition.md` records the complete read-only disposition of the source
CLI-skill family: portable workflow rules are separated from client-specific command
rendering and excluded workplace bindings.

`individual-disposition-register.md` is the complete 112-unit source inventory. Every
configuration, command skill, tool, migration, role, contract, skill, gate, and script
has one explicit outcome: adapt, optional, exclude, defer, merge, split, or retain as
evidence. It records no source workspace names, values, credentials, or topology.
