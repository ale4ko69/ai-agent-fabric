# Intake

Work class: small-bug. Owner direction requests a verifiable chat-based owner authorization for an already Kepler-reviewed planned task, bound to the exact task, reviewed artifact digest and verdict. Material changes or expiration must invalidate it; existing interactive-terminal records remain valid. No global auto-approval, weakened Guards, or retroactive approval of another task is authorized.

The activation packet delegates this task's lifecycle to the claimed Socrates chat and authorizes bounded commit, push, PR, merge and versioned release after successful review and validation. It identifies the owner's mobile chat direction as provenance for this task's scope; it is not terminal input and does not authorize future reviewed packages.

Repository baseline: origin/main after fetch. Other task packages and worktrees are outside scope.
